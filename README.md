# PG3b Terraform Expansion — Interactive UX Concept

Internal IBM strategy concept for reviewing digital-first expansion from existing **paid HCP Terraform** customers to adjacent capabilities presented as **Concert Observe (Instana)**, **Concert Optimize (Turbonomic)** and **Concert Protect**.

## View

Open `index.html` in a browser or enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save).

## Try the demo

- Explore the Terraform run and resources screens.
- Open **Presenter Mode** to switch between Observe, Optimize, Protect and a neutral no-expansion scenario.
- Switch to **Bob Assistant** and test task-driven discovery and the proposed link-based activation handoff.
- Test the **Sales-assisted evaluation** simulation and return to the originating workflow.

## Scope and limitations

This is a **standalone synthetic prototype**, not a live IBM integration or confirmed product roadmap. UI, entitlements, trial and evaluation requests are simulated; nothing is submitted to IBM sales systems. It loads React, Babel, Tailwind and IBM Plex font resources from external CDNs and therefore requires internet access.

Do not use real credentials or customer data. Keep the repository private or use company-approved controlled hosting if access to internal IBM strategy must be restricted.
